## Read

- **Nobody holds "PILOT" for developer tooling / AI coding agents.**
- **Our own "PILOT" filing would likely be refused** — same word, same class 42, three prior
  registrants; examiners cite likelihood of confusion across differing goods within a class.
- **Use risk: low-moderate.** Bookkeeping SaaS vs. an engineering-team coding agent = different
  buyers/channels; a Pilot.com letter is possible (well-funded, counsel on file) but the
  confusion argument is weak. Charter / Pilot Inc. are non-issues.
- **What would register:** a compound with the house mark ("QuantFlow Pilot", "Pilot by
  QuantFlow"); "PILOT CLOUD" alone is descriptive.

**How to apply:** don't file bare "PILOT". If a registration is wanted, file the house-mark
compound. Before phase 2 goes public, do the EU/UK manual check. Feeds
[[domain-pilotcloud-dev-keep-pilot-name]].
