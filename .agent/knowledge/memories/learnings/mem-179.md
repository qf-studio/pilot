# Learning: Auto-init must own its consumption contract — and green CI on a runner without the production artifact proves nothing

## Summary
GH-5216→PR#5219 fixed Pilot's auto-init no-ops (context-injection headers, FEATURE-MATRIX anchor, knowledge tree seed) by editing the *embedded* template — but `Initialize()` prefers the installed Navigator plugin's templates (`FindTemplatesPath`), and the plugin's own template (6.18.1) lacks all three headers `loadProjectContext()` extracts. So the fix was bypassed everywhere the plugin cache exists — including the production box — while CI stayed green because runners have no plugin cache. Caught only by running the new regression test on a plugin-bearing laptop (failed: "got empty string"). Durable fix GH-5221→PR#5224: `ensureContextSections` enforces the three headers after template copy regardless of source (append-only, idempotent), plus HOME-isolation (`t.Setenv("HOME", t.TempDir())`) for every test that touches the plugin-cache discovery path.

## Context
Session 2026-08-25: docs-site review surfaced that auto-init's scaffold silently disabled two advertised features (GH-1387 context injection, GH-1388 feature-matrix update) and never seeded the knowledge tree `graphrecall` reads per execution. Fix chain #5216→#5219 (review: APPROVE-with-defect) → #5221→#5224 (review: APPROVE, verified on plugin-bearing machine).

## Details
Two reusable lessons:
1. **When a component consumes files it also scaffolds, the invariant belongs at the consumer's contract, not in one template variant.** Any code path with multiple content sources (installed plugin > embedded fallback) must post-process to guarantee what downstream extraction needs — fixing one source silently loses to source precedence.
2. **Environment-dependent test truth:** a test that depends on host state (`~/.claude/plugins/cache/...` via `os.UserHomeDir`) passes on bare CI and fails on developer/production-like machines — the green CI signal is anti-correlated with the environment that matters. Isolate with `t.Setenv("HOME", t.TempDir())` and add an explicit fabricated-cache test for the production path (assert the intended source won before asserting behavior).

Residual: repos auto-inited before v2.270.0 keep header-less READMEs (`IsInitialized` short-circuits); they self-heal when a session fills sections. Upstream: the Navigator plugin template itself should gain the three headers (founder's repo, alekspetrov/navigator).
