# Learning: AWS CLI pager stops shell loops; a pasted multi-line loop may run one iteration

## Summary
A for-loop over aws CLI calls halts in the pager after the first JSON result (the user sees '(END)'); quitting the pager then runs the remaining iterations and re-writes already-written values (SSM parameter version 2 = same value twice, harmless). A loop pasted into the prompt can also lose its 'done' line and run once.

## Context
2026-10-05 TASK-502: writing pool-01..05 SSM SecureStrings; only pool-01 landed from the pasted loop, then 02–05 arrived as v2 after I had written them from the session.

## Recommended Approach
In loops and scripts: export AWS_PAGER='' or pass --no-cli-pager and --output text; verify with a names-only listing afterwards (aws ssm get-parameters-by-path --query 'Parameters[].Name') before re-running; re-writes with --overwrite are idempotent.
