# Learning: Docs PRs of one planning session: start each from origin/main after the docs PR 

## Summary
Docs PRs of one planning session: start each from origin/main after the docs PR before it merged. A branch on top of a pending docs branch conflicts after the squash merge (twice on 2026-11-17 and 11-18), and a merge of main into it brings Go files into the push, so the pre-push gate runs the full test suite. When a dispatch cannot wait: edit and dispatch on a local branch, commit locally, and rebuild on main with git checkout COMMIT -- FILES. Restore graph.json with git checkout -- before each graph command, because a hook rewrites it and drops issue links.
