# Learning: Whole-package test runs in a review (2026-11-27): the Go default limit of 10 min

## Summary
Whole-package test runs in a review (2026-11-27): the Go default limit of 10 minutes for a package is too short for the executor test package on a laptop (842 s); the CI passes -timeout 20m. Pass -timeout 25m. To prove that tests leave nothing in the temporary directory, run the package with TMPDIR set to a fresh empty directory and list it after the run, on the merge commit and on its parent; a run that stops at the time limit proves nothing, because a killed test skips its clean-up.
