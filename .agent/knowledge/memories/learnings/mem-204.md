# Learning: Founder-token PRs accept a verdict only as a COMMENT review; APPROVE and REQUEST_CHANGES are refused

## Summary
GitHub refuses both APPROVE and REQUEST_CHANGES on a pull request whose author is the same token that reviews it (the founder token opens Pilot's PRs in pilot-console, pilot-console-ui and auth-service). The verdict still has to land on the PR for the review ledger, so post it as a review with event COMMENT whose first line is the verdict (APPROVE-w-notes / REQUEST-CHANGES) — done 7 times on 2026-09-29 without a single failed call. Autopilot does not read the review event, it merges on green, so a REQUEST-CHANGES comment does not hold the PR: file a revision issue in the same minute.

## Context
