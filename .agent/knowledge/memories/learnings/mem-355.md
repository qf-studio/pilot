# Learning: run_as_user proof limit (2026-11-27): each of the 19 ticket runs with the option

## Summary
run_as_user proof limit (2026-11-27): each of the 19 ticket runs with the option on the founder box (11-26 and 11-27) was in a public repository (the Pilot repository and the SDK repository). The agent user has no GitHub credential: the read token for a run comes only from a GitHub App in the daemon config, and the daemon logs the Warn 'no GitHub read token for the agent'. A run as the agent user in a private repository is not proven. Say 'N runs, all public' in a report, not only 'N runs, no failure'; a customer box of Pilot Cloud runs private repositories, so the first proof there is one ticket in the private repository of the canary.
