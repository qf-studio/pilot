# Pattern: The only hook for acting on a Claude usage-limit failure is Dispatcher worker.on

## Summary
The only hook for acting on a Claude usage-limit failure is Dispatcher worker.onRateLimited (single func field, dispatcher.go:3444) wired to armUsageLimitPause (dispatcher.go:3109); pause state is usageLimitResumeAt/usageLimitGen/usageLimitTimer with owner 'usage-limit' on PauseAdmissionFor. There is no runtime config path: Config.Reload has no callers, every 'pilot X set' edits config.yaml offline, the gateway has no config-mutating endpoint. A runtime override store is the missing primitive (TASK-631 A2, also needed for 'pilot pause').
