# Pattern: Recover a commit that exists only on the founder box (refs/pilot-recovery/GH-N a

## Summary
Recover a commit that exists only on the founder box (refs/pilot-recovery/GH-N after a rejected push): the box has no git credential outside the daemon, so create a git bundle of main..recovery-ref as ec2-user, base64 it, read it over SSM in chunks of 18 KB or less, verify the sha256 and the commit SHA, fetch the bundle into a laptop worktree and push with force-with-lease on the stale head. An open PR on pilot/GH-N is safe for the pipeline: the poller's open-PR admission gate (GH-6020) skips a second run and autopilot adopts the PR. Delete remote refs through the GitHub API, because git push --delete runs the full 12 minute pre-push gate.
