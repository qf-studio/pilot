## Summary
Read guard stays a substring matcher (founder decision 2026-11-11). Three attempts at a token-aware matcher (PR #6285 reverted, PR #6299 closed) each failed a black-box review: reads through another program passed (runner outside a wrapper list, full-path wrappers, here-strings), some inputs were superlinear, and the ancestor rule blocked usual commands. A shell-command parser in sh/awk finds a new bypass family in every round, while a false block of the substring matcher costs the agent one retry. The boundary against reads of Pilot data is the separate agent uid (TASK-650 H1); do not reopen the precision work before H1 ships.
