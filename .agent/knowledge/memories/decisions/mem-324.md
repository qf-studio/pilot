## Summary

No git fetch and no bundle on an agent stream: a thin bundle copies a private commit into the new pack, a broken bundle header starts the repository transport on the file, a filter capability and a partial clone make git fetch objects that the agent names (GIT_NO_LAZY_FETCH=1 closes the last one).
