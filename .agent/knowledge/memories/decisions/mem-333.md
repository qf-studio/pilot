# Decision: Founder decision 2026-11-23: no draft holds. The delivery of Pilot is autonomous

## Summary
Founder decision 2026-11-23: no draft holds. The delivery of Pilot is autonomous, so a session never converts a pull request of Pilot to a draft and never asks the founder for a merge word; a review comes after the merge and its findings go into follow-up tickets. This ends the one exception of 2026-11-19 (the pull request that removed the preflight refusal of run_as_user was held as a draft, PR 6684; the founder released it the same day and asked to stop the practice). Fact behind it: the daemon has no path that opens or makes a draft; it only refuses to merge one (handleMerging, GH-5263), and the dashboard shows such a hold as the stage merging, which reads as a stuck merge.
