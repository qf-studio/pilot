# Pitfall: Three facts that a plan for another repository must check on the live box first 

## Summary
Three facts that a plan for another repository must check on the live box first (TASK-657, 2026-11-23/24): (1) the daemon config may have no project for that repository (the infra repository had left the config in September; three tickets waited until the project block came back with an empty required-checks list); (2) the size check holds a pull request with more than 500 new lines in the stage awaiting_approval until the founder approves in Slack (a 1,821-line script copy waited 16 hours); (3) the host script setup-agent-user.sh changes no directory mode itself: its first step prints chmod lines for an operator and fails, and it never removes a group membership, so a wrapper needs one mode for each of those steps.
