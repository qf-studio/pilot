## Summary
A long uptime of the daemon process on the box is no sign of old code: the self-upgrade restarts by exec and keeps the process ID. Read the running version from the build metric (pilot_build_info) or the line 'upgrade verified complete' of the daemon log before a restart is proposed. On 2026-11-23 a session marker said the daemon did not run the merges of two days before and listed a restart as a founder decision; the daemon had upgraded itself 28 minutes after the last merge. The same session found that an answer of the infrastructure owner had been in the founder's Slack for five days while the records said 'no answer': search the message channel before a record repeats 'no answer'.
