## Recommended Approach
When a pre-PR fix round (or your own review) accepts a deviation from the issue text: edit the issue body (Scope + Tests) to the new shape before the merge, and say so in the PR body's evidence. If the post-merge round already filed a fix: prepend a steer to the fix issue (specs-only, do not revert) before the executor picks it up.
