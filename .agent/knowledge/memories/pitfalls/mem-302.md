# Pitfall: A security PR was approved from the Slack merge ask before the run-it review age

## Summary
A security PR was approved from the Slack merge ask before the run-it review agent finished: PR #6285 (read guard token matcher) merged 2026-11-10 and was reverted 30 minutes later (PR #6289) when the black-box review found bypass regressions and a 15 s runtime on a 10 KB command. The pre-PR review reads code and does not run commands. Report every security PR with an explicit hold line in the same message that announces it, and give go or no-go only after the black-box result.
