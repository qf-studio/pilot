# Pitfall: The mutation check of the acceptance evidence changes a file of the work tree, r

## Summary
The mutation check of the acceptance evidence changes a file of the work tree, runs a test and writes the first content back; a failed restore, or a changed write that fails after the file was cut, left the changed file in the tree, and the run went on to the review and the push with no log line (found 2026-11-20 in the review of PR 6605; true with run_as_user off too; fix in issue 6606: read the file again after each mutation line, repair by a second write and git checkout, else stop the run before the push).

## Context
Discovered during development.
