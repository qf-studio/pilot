## Summary
executions.key_source is an env-var label (PILOT_ANTHROPIC_KEY_SOURCE, stamped once at lifecycle.Begin), not derived from the credential the claude subprocess actually used; it means platform-vs-own owner, not subscription-vs-api_key. Any billing-mode feature needs its own credential-derived column; quality gates and git inherit the full daemon env (quality/runner.go:509, git.go:1073), so ANTHROPIC_API_KEY reaches project test commands today.
