# Pitfall: GitHub App and the founder box (2026-11-27): Pilot in the terminal needs no GitH

## Summary
GitHub App and the founder box (2026-11-27): Pilot in the terminal needs no GitHub App; the daemon works with a normal token. The only GitHub App that exists belongs to Pilot Cloud (console plan), and its key must never go onto the founder box: the key can mint a token for each customer installation and the box runs agent code. Founder decision of 11-24, confirmed 11-27: no private App for the founder box. On 11-27 a session told the founder to write the App key to a Parameter Store path of the founder box, because a shared request list asked for that path and the infrastructure owner had answered it; the sandbox pool shares the role of the box and can read the path. Rule: before a step that moves a key, read the recorded decision for that key in the task document (TASK-657, section 'Which GitHub App'), not only the last request list.
