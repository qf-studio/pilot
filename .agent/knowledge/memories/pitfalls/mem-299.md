# Pitfall: Git hooks that find the repo root as $HOOK_DIR/../.. validate the main checkout,

## Summary
Git hooks that find the repo root as $HOOK_DIR/../.. validate the main checkout, not the worktree: worktrees share .git/hooks, so the pre-push gate and the pre-commit graph check ran against root files and blocked two TASK-646 pushes for files the pushed commit deletes. Resolve the root with git rev-parse --show-toplevel. Never pipe git push through tail: the failing gate step scrolls off; log to a file. Fix filed as #6218.
