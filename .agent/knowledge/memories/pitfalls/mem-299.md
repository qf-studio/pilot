# Pitfall: A page root with grow basis-0 min-h-0 is for pages with an internal scroll column; a long document page inside the min-h-full container needs a plain flex root

## Summary
TASK-645 A1 copied Home's root (flex min-h-0 grow basis-0 flex-col) onto the ticket page. Home pins a composer and scrolls inside HomeGridLayout, so the root must equal the container height. The ticket page is a document that scrolls in <main>: basis-0 fixed the root to the container's height, the grid overflowed it (2029 px vs 1586 px), and <main>'s 22 px bottom padding landed above the content (0 px gap at the page end). The specs could not see it (jsdom); the live measurement did. Fix: root flex flex-col, so the container's min-h-full grows with the content.

## Recommended Approach
Choose the root by scroll model: internal scroll region (pinned composer) → grow basis-0 min-h-0; document page → flex flex-col. After every layout leg, measure main.scrollHeight vs the container bottom and the gap below the last element at the page end — in a browser, not jsdom.
