# Pitfall: The daemon user on the box had (ALL) NOPASSWD: ALL from cloud-init, so every age

## Summary
The daemon user on the box had (ALL) NOPASSWD: ALL from cloud-init, so every agent session could become root for months; no guard covered it (the bash guard blocks only a sudo rm substring) and one agent run did call sudo. Found 2026-11-12 during the TASK-651 design, removed the same day (operator step O1, backup in /root). Before any reasoning about what an agent can or cannot read or do on a host, run sudo -l -U for the daemon user and read the sudo journal; on a new host remove the cloud-init rule before the daemon starts.
