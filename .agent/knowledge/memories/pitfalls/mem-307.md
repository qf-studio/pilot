# Pitfall: A GitHub Actions run can stay queued forever: PR #6317 got a CI run on 2026-11-1

## Summary
A GitHub Actions run can stay queued forever: PR #6317 got a CI run on 2026-11-11 20:41Z that never started (other PRs ran normally), autopilot hit two 30 minute CI timeouts and set the PR to failed, and it does not revive a failed PR when checks go green later. The dead run can be neither cancelled ("completed"), force-cancelled ("not been queued yet") nor re-run ("already running"). Fix by hand: update the PR branch with main through the API (pulls/N/update-branch), which makes a new head and a new run; then review and merge by hand, because the autopilot stage stays failed.
