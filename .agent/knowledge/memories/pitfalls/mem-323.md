# Pitfall: The daemon files its own follow-up ticket (post-merge-review minors) for a merge

## Summary
The daemon files its own follow-up ticket (post-merge-review minors) for a merged PR, and that ticket can change the same files as the next planned leg: issue 6480 was built on main from before PR 6485 merged and its PR 6486 got a conflict in four files that the auto-rebase could not solve (2026-11-18). Before a dispatch, look for an open ticket with the label post-merge-review on the same files and wait for it; a conflicted PR is closed and the ticket runs again on the new main.
