# Pitfall: A new mode knob must treat 'unset' as today's behaviour, never as one of the new

## Summary
A new mode knob must treat 'unset' as today's behaviour, never as one of the new modes: GH-6016 (v2.310.0) made unset billing.mode mean subscription, and subscription strips an inherited ANTHROPIC_API_KEY from every model subprocess, so every hosted tenant (env key from /run/pilot/env, no OAuth login, no billing block) would start the claude CLI with no credential on upgrade. Caught 2026-11-03 before any tenant upgraded (2.282.0/2.277.4). Before specifying a default, enumerate every deployment shape that relies on the old implicit behaviour (founder box = OAuth token, tenants = env key, self-hosted = either). Fix: TASK-633 F4 pilot#6032 (unset = passthrough + derived attribution).
