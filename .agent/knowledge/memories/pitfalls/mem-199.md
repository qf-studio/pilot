# Pitfall: AWS WAF LinuxRuleSet LFI_QUERYSTRING blocks any query string ending in README.md; the console docs-file route 403s on both fleet ACLs

## Summary
Docs page 'Something went wrong' on the first fleet tenant was not a missing file: GET docs/file?path=DEVELOPMENT-README.md is blocked 403 by AWSManagedRulesLinuxRuleSet rule LFI_QUERYSTRING on BOTH the CloudFront ACL (pilot-fleet-cdn-web-acl) and the regional ALB ACL (pilot-fleet-web-acl). Probes: any query ending in README.md is blocked, system/FEATURE-MATRIX.md passes, appending a second param passes. Neither the daemon docs handler nor the console proxy ever emits 403, so a 403 with an HTML body on this path is always WAF. Fix filed infra#18: ScopeDownStatement excluding URI paths ending /pilot/docs/file from the Linux rule group in both templates, no fleet-wide Count override.

## Context
2026-09-25, first fleet tenant Docs page; tree loaded, first file click failed. Located via ALB-direct curl (WAF default 403 body) vs CloudFront (Request blocked page) and wafv2 get-sampled-requests naming the rule.

## Recommended Approach
For a 403 on the console: check the body. JSON = console-api or daemon; CloudFront 'Request blocked' HTML or the bare '403 Forbidden' HTML = WAF. Then run aws wafv2 get-sampled-requests on both fleet ACLs (CLOUDFRONT scope in us-east-1, REGIONAL in eu-central-1) for the linux/common rule metrics to get RuleNameWithinRuleGroup. Prefer a route-scoped ScopeDownStatement over a Count override; the daemon path allowlist is the real guard.

## Resolution (2026-09-28)
Nelya replaced our route-wide scope-down (infra PR#19, never deployed) with a narrower rule on main: `LFI_QUERYSTRING` relaxed only for a docs-file request whose decoded query contains no `..`; the rest of the Linux rule set stays on for the route. Verified from the account side (README passes → 401 without session; `../etc/passwd` plain and encoded still blocked) and from the browser (tenant Docs page renders `DEVELOPMENT-README.md`). WAF changes on the fleet ACLs are hers to make — file the ask, do not open a PR (mem-201).
