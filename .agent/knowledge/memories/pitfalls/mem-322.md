# Pitfall: A parked ticket (pilot-needs-human after a pre-PR review with a blocking defect)

## Summary
A parked ticket (pilot-needs-human after a pre-PR review with a blocking defect) is not fixed by a comment plus the removal of the label: the daemon opens the PR for the pushed branch as it is, with no new agent run, and the defect merges (PR 6484, 2026-11-18). After a retry, compare the commit of the PR with the commit of the hold comment before a report; when they are equal, file a fix ticket.
