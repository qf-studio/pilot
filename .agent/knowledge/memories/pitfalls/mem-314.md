## Summary
A spec for a security control must not prescribe a mechanism that the attacker can reach. TASK-650 L8 asked for an empty hooks directory in the daemon temp directory; a session of the same Unix user found it and wrote a pre-push hook into it (review of PR #6348). Prescribe the property (no hook can run), prefer a value that cannot exist on disk (a path below /dev/null), and let a research pass confirm the mechanism before the spec names it.
