## Summary
A merged pull request is not on the box until a release holds it: the release train runs once a day (about 15:04Z) and only when a non-docs commit is on main. On 2026-11-24 a session set run_as_user on the founder box while the daemon ran v2.326.0 (tag of 11-21); the removal of the preflight refusal (PR 6684, merged 11-23 15:34Z, after the train of that day) was in no release, so the start check refused and the daemon could start no model process for 51 seconds until the rollback. Before a box test of a code change run: git tag --contains COMMIT, and compare with the version of the build metric on the box.
