# Pitfall: A helper file at a fixed name in the shared temporary directory breaks under a s

## Summary
A helper file at a fixed name in the shared temporary directory breaks under a second Unix user: gitAskpassHelperPath wrote os.TempDir()/pilot-git-askpass.sh; on the founder box the daemon user owned that file, so the package tests of internal/executor, run by the agent user in the test gate (run_as_user set), got 'permission denied' and 19 tests failed (first run on a Linux host, 2026-11-24, issue 6694). The same pattern lets another local user make the file first. Use os.MkdirTemp for each process, and search for other fixed names below the temporary directory before a host gets a second user. A macOS run with a mock sudo cannot show this class: both sides are the same user there.

Discovered during development.
