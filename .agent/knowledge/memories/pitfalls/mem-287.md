## Summary
The pre-PR review fix round re-gates under a hard-coded 5-minute shared cap (reviewFixRegateTimeout, internal/executor/pre_pr_fix.go:27) and treats the resulting 'context cancelled' as a red test (status reverted). On the founder box the test gate takes 5m30s-17m on pilot and 4m02s-5m27s on pilot-console-ui, so the cap is a coin flip on every project (GH-370 fixed at 4m58s, GH-6109 reverted at 5m00s).
