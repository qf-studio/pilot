# Pitfall: Go tests of Pilot leave directories in the temporary directory of the host (foun

## Summary
Go tests of Pilot leave directories in the temporary directory of the host (found 2026-11-27 on the founder box): about 5,700 top-level entries in one month, with the prefixes worktree-local-, worktree-remote- and wire-fields, plus the set-up script test; about 70 new entries each day from the quality gate runs, owned by the daemon user and since 11-26 by the agent user. On the box the temporary directory is tmpfs, so the leftovers use memory. A hand clean-up removed the entries older than 24 hours; the cause is in TASK-660 (ticket pilot#6733): a test helper that gives back two directories with no clean-up of its own, and callers that drop a path. Correction of 11-27 16:03Z: the about 1,280 directories with the prefix pilot-worktree-GH-5399 are test output too, not daemon worktrees; one test uses the task ID GH-5399, keeps its worktree on purpose and never removes it, and each directory points to a git directory of that test that is gone. Rule: read the git pointer of a leftover worktree on the box before a statement about its owner.
