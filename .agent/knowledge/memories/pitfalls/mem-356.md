# Pitfall: Go tests of Pilot leave directories in the temporary directory of the host (foun

## Summary
Go tests of Pilot leave directories in the temporary directory of the host (found 2026-11-27 on the founder box): about 5,700 top-level entries in one month, with the prefixes worktree-local-, worktree-remote- and wire-fields, plus the set-up script test; about 70 new entries each day from the quality gate runs, owned by the daemon user and since 11-26 by the agent user. On the box the temporary directory is tmpfs, so the leftovers use memory. A hand clean-up removed the entries older than 24 hours; the cause (tests that make a directory with os.MkdirTemp and do not remove it, where t.TempDir removes it) has no ticket yet. About 1,280 worktree directories of one old ticket (GH-5399) are a second, different leftover: daemon worktrees, not test output.
