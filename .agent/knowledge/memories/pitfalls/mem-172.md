# Pitfall: Backticked glob paths in a pilot issue body poison dispatch pre-v2.267. ExtractR

## Summary
Backticked glob paths in a pilot issue body poison dispatch pre-v2.267. ExtractReferencedPaths accepts globs (e.g. cmd/pilot/*.go in backticks), the base-presence probe 404s on the literal glob, and the task is held at the queue HEAD -> starves everything behind it (breaker alerts every 30min; queue only re-evaluates on NEW dispatch, so claim-lost re-pickups never wake held workers). Fix shipped #5133/PR#5135 (glob exclusion + wakeHeldWorkers on stale-recovery tick). Until v2.267 is on the box, do NOT put backticked glob paths in issue bodies; cite concrete files or plain text.
