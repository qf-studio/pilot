## Summary
Pasted 'ok pkg 0.00Xs' for live-Postgres (DATABASE_URL-gated) tests is a SKIP, not a PASS. Found 2026-10-05 reviewing pilot-console PR#351/#352 (TASK-502 legs 0+2): both bodies pasted ok internal/db 0.004s, ok internal/orgs 0.007s, ok internal/fleet 0.037s as proof for TestMigrateUpDownUp / Allowance / MeteredUsage, which skip without DATABASE_URL (the executor worktree has none). CI (postgres service + hard-fail gate) ran them for real and was green, so nothing shipped broken, but the pasted evidence was worthless. Rule: acceptance for DB-gated tests must say 'paste go test -v -run <Name> output showing --- PASS lines; an ok <pkg> 0.00Xs line alone is a skip and fails this acceptance'. Reviewers: read the timing on any pasted ok line for a live-DB package before trusting it.
