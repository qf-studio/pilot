# Pitfall: Hand-filed review follow-ups race the automatic post-merge fix issues on the sam

## Summary
Hand-filed review follow-ups race the automatic post-merge fix issues on the same files: on 2026-11-10 the follow-ups #6284 and #6287 ran while autopilot filed and merged post-merge minors (#6286, #6288, #6301) for the same PRs, and both follow-up PRs (#6297, #6299) ended CONFLICTING with needs-manual-rebase. Before filing a follow-up for a merged PR, check for an open post-merge-review issue on it; fold its items into the follow-up or add Depends on, and expect a hand merge of main otherwise.
