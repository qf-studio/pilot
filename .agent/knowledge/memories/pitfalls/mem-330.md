# Pitfall: scripts/nav-dispatch-legs.py accepts a leg ID only in the form capital letters p

## Summary
scripts/nav-dispatch-legs.py accepts a leg ID only in the form capital letters plus digits (H12, U41); an ID such as U4a gives 'no legs found' with no other message. Its path check also reads each backticked text with a slash as a repository path: a config key such as credential.https://github.com.helper in backticks fails the dry run. The task document guard of Navigator accepts a new task file only when the nav-task skill ran while the shell stands in the same worktree as the file.
