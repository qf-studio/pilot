# Pitfall: Daemon self-upgrade re-execs the new binary with the OLD process environment: a 

## Summary
Daemon self-upgrade re-execs the new binary with the OLD process environment: a config line referencing a new ${VAR} (sensitive key) makes the upgrade restart fail closed (procs=0) until a wrapper restart loads start-pilot.sh. Rule: add the export + wrapper restart BEFORE the config line rides a release; and never put a $word in a YAML comment — the loader's env pre-scan flags it. TASK-510, 2026-10-02 08:44Z.
