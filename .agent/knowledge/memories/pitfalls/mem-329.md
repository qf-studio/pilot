# Pitfall: A test that proves an allow list with probe names that end in _SECRET, _TOKEN or

## Summary
A test that proves an allow list with probe names that end in _SECRET, _TOKEN or _KEY proves nothing when an older deny filter removes such names first: with the allow list removed the test still passed and a quality gate saw 93 names of the daemon (PR 6580, found 2026-11-19 by a mutation in the run-it review). Use probe names with no denied ending (DAEMON_ONLY_VALUE, SSH_AUTH_SOCK) and assert that every name of the child environment is in a fixed list. The same class: a guard that is tested by a call of the guard function and not through the production call sites (PR 6591).

## Context
Discovered during development.
