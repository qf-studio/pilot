# Pitfall: Release train (on_schedule) member resolution requires (#N) squash-title suffix 

## Summary
Release train (on_schedule) member resolution requires (#N) squash-title suffix — autopilot's auto-merger omits it, so trains over autopilot-merged commits skip forever ('no resolvable member PRs'). Cutover order: ship GH-4150 (#N suffix fix) FIRST, then flip trigger on_merge → on_schedule (schedule '0 16 * * 1-5', schedule_timezone Europe/Berlin); flipping first silently halts releases (merges held, train skips daily). Evidence: 8/9 commits in v2.236.4 lack (#N); v2.236.4 cut on-merge at 22:14 because config never followed the mem-104 train decision. Refs: internal/autopilot/scope_schedule.go resolveTrainMemberPRs, auto_merger.go commitTitle.
