# Pitfall: Boot reconcile (dispatcher.go ~516, GH-4392) marks a claimed QUEUED row stalled 

## Summary
Boot reconcile (dispatcher.go ~516, GH-4392) marks a claimed QUEUED row stalled like a dead running owner, and the stalled re-arm sweep (cmd/pilot/rearm_stalled.go ~341-396, rearm_canceled.go ~112) accepts only re-arm evidence timestamped after the stall, so a retry the daemon itself queued (pilot-retry-ready added before the restart) is escalated to pilot-needs-human after three checks (~4 min). A daemon restart therefore turns a waiting retry into a human task. Seen 2026-11-06 pilot#6152 16:44-16:48Z. Fix: TASK-641 D3 — re-queue queued rows at boot; count pre-stall daemon re-arms as evidence.
