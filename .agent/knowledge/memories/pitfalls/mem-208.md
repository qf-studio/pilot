# Pitfall: A GitLab personal access token (classic or fine-grained) acts with the USER'S ro

## Summary
A GitLab personal access token (classic or fine-grained) acts with the USER'S role: 'Maintainers may push' protection on main does not stop an Owner's token — a probe push landed an empty commit on a prod-deploying main and started a pipeline (cancelled in build). Lock protected branches to push=No one / merge=Maintainers so every change goes through an MR; verify with the token (pilot/* push ok, main rejected). TASK-510, 2026-10-02.
