# GH-4709

**Created:** 2026-08-04

## Problem

GitHub Issue GH-4709: feat(alerts): reusable dead-man tracker — generalize the intent-judge streak counter; register label-lifecycle + self-review liveness (TASK-441 L2)

## Context

TASK-441 Leg 2 (`.agent/tasks/TASK-441-contract-hardening-tune-up.md`). GH-4685 ended the intent judge's 17-day silent death with a bespoke streak counter (`sdkPreFlightJudge` wrapper firing `alerts.EventTypeIntentJudgeFailureStreak` at threshold=10, reset on success — `cmd/pilot/poller_github.go`). That pattern must be a reusable primitive, not a per-seam hand-rolled wrapper: the same silent-death class hit the label lifecycle (GH-4687, dead 19 days) and self-review (GH-4702, months).

The alerts engine already holds per-key streak state (`consecutiveFailures map[string]int`, `internal/alerts/engine.go:26`, used by `AlertTypeConsecutiveFails`) and typed extensible alert rules (`internal/alerts/types.go:17-67`).

Key design lesson (memory `poller-labels-removed-log-means-never-applied`): liveness must count **attempts and successes separately** — absence of errors is not liveness; a subsystem wired to nothing produces no errors at all. Zero-successes-while-attempts-flow AND zero-attempts-while-tasks-flow are both alertable states.

## Acceptance

- A reusable tracker (e.g. `alerts.ConsecutiveFailureTracker` or an engine extension): register(name, threshold, window); record attempt/success/failure; fires one alert at threshold, resets on success; exposes both counters.
- Intent-judge streak counter migrated onto it with identical externally-observable behavior (same alert type/threshold — its alert contract is now watched by ops).
- Two new registrations: label-lifecycle notify (post-GH-4692 `notifyTaskStartedSDK` path) and self-review completion.
- Table-driven tests: streak fire-once, success reset, zero-attempts detection.
- **Freeze constraints**: Prometheus metric names are additive-only (existing `pilot_*` names unchanged — grafterm dashboards consume them); no config schema changes; no label vocabulary changes.

## Implementation

- `internal/alerts/{types,engine}.go`: primitive + one generic AlertType (or reuse), keeping the existing `AlertTypeIntentJudgeFailureStreak` emission intact.
- `cmd/pilot/poller_github.go`: migrate judge wrapper; add the two registrations at their call sites.
