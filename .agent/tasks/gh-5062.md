## Problem

GitHub Issue GH-5062: ci(check-mocks): extend argument-discarding-mock gate beyond Backend.Execute — QualityChecker.Check class (GH-5060 blindness)

## Context

GH-5060's root cause was test blindness: `sleepThenFailQualityChecker.Check(_ context.Context)` discarded its ctx, so the fresh-ctx tests could not see that the gate re-check still ran on the exhausted attempt ctx. The repo's argument-discarding-mock CI gate (`scripts/check-mocks.sh`, wired in ci.yml:28) only scans **`Backend.Execute` mocks** — it structurally cannot catch this class on any other interface.

## Task

Extend `scripts/check-mocks.sh` to also flag argument-discarding mocks of `QualityChecker.Check` (pattern: `Check(_ context.Context)` / unused ctx param on types matching `*QualityChecker`/`*qualityChecker` in `internal/executor/*_test.go`). Follow the existing script's grep idiom and allowlist mechanism. Consider whether other high-value interfaces (e.g. `ExecutionSaver`) deserve the same pass — state the choice rather than silently scoping to one.
