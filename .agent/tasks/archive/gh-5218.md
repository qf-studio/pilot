# GH-5218

**Created:** 2026-08-25

## Problem

GitHub Issue GH-5218: chore(scripts): package git-config-watch as an armable service (make target + systemd unit + launchd plist, single-instance) so occurrence №5 isn't missed

## Context

`scripts/git-config-watch.sh` (GH-5063, merged in PR#5208) is the forensic tripwire for the still-unidentified writer that has flipped the shared git config's core.bare false→true four times (2026-07-28, 08-18, 08-21, 08-24), breaking every concurrent session at once. By design it is passive operator-opt-in tooling — and in practice that means nothing runs it: occurrence №5 will be missed unless an operator happens to have a tmux pane open. The script's own header documents the ad-hoc tmux recipe for both the laptop and the founder box, but there is no packaged way to keep it armed.

Known negative (2026-08-24): SIGTERM'ing the pre-push gate mid-test did NOT reproduce the flip — the watcher must be armed continuously around push activity, not only while the gate runs, and must not be wired INTO the gate (the gate is itself a suspect).

## Task

Do not decompose this issue — it is a single-subsystem change that must land as one PR.

Package the watcher so arming it is one command per machine, still operator-initiated, never automatic:

1. Makefile target watch-git-config that execs `scripts/git-config-watch.sh` in the foreground (thin wrapper, inherits GCW_* env vars).
2. A systemd user-unit file, committed as a new file under scripts/ (suggested name git-config-watch.service, alongside the script), with Restart=on-failure and the forensic log at a stable path, plus install/enable instructions in its comment header — for the founder box, where pushes come from autopilot and no tmux pane survives. The unit is shipped disabled; enabling it is an operator step.
3. A launchd plist equivalent for macOS, also committed under scripts/ (suggested name com.pilot.git-config-watch.plist), same shipped-disabled contract — for the laptop push context.
4. Single-instance guard in the script itself (lockfile or pgrep check): a second launch must refuse and point at the running instance, so the unit + a stray manual tmux copy never double-heal or interleave forensics.
5. Update the script's header How-to-run section to document all three paths (make target, systemd, launchd) and state the shipped-disabled contract.

No cron, no CI wiring, no automatic start from any daemon code path — this stays operator-armed. Shell only; no Go changes.

## Acceptance

- [x] make watch-git-config runs the watcher from the repo root and from a linked worktree.
- [x] Second concurrent launch exits non-zero with a message naming the running instance (test via the script's own test harness style used by Box Scripts CI — ShellCheck must pass).
- [x] Unit/plist files pass a syntax check (systemd-analyze verify is not available on macOS CI — a comment-documented manual step is acceptable; ShellCheck covers the script changes).
- [x] Script header documents all run modes; shipped-disabled contract stated in both unit files.
