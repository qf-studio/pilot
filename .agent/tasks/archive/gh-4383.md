# GH-4383

**Created:** 2026-07-17

## Problem

GitHub Issue GH-4383: fix(dashboard): autopilot panel renders awaiting_approval as 'rebase retry N/3' — wrong stage label during approval outage

## Context

The dashboard AUTOPILOT panel renders PRs stuck in `awaiting_approval` as stage **"rebase"** with **"⟲ retry N/3"**. Observed live 2026-07-16 19:49Z:

Panel: `#4379 … ■■■■■ rebase 1h30m / retry 3/3` and `#4382 … ■■■■■ rebase 8m / retry 2/3`
Ledger truth (`autopilot_pr_state`): both rows `stage=awaiting_approval, ci_status=success, merge_attempts=0, rebase_attempts=0`, error = approval-submit send failure (the GH-4380 regression). Log confirms: `awaiting approval before merge` — no rebase was ever attempted.

Operator impact: during the approval-delivery outage the panel told the founder his PRs were failing rebases — a wrong-root-cause panel during an active incident (third panel-truthfulness defect this week, after HISTORY frozen rungs #4368/#4369 and QUEUE alignment #4338/#4340).

Single concern, **do not decompose**. <!-- pilot:no-decompose -->

## Approach

1. Find the autopilot-panel stage/retry mapping in `internal/dashboard` (the widget rendering PR rows with the segment meter + "retry N/M" suffix) and fix the mapping: `awaiting_approval` must render as its own stage label (e.g. `approval`), with elapsed time since `approval_requested_at`.
2. The "retry N/M" counter currently shown appears to source from the approval-submit/circuit-breaker retry loop — either label it truthfully (`send retry N/M`) or drop it for non-rebase stages; "rebase" must only appear when `rebase_attempts > 0` or the controller is actually in the rebase/update-branch path.
3. Table-driven test: a PRState in `awaiting_approval` with a submit error renders `approval` + error hint, never `rebase`.

## Acceptance

- A PR whose ledger row is `stage=awaiting_approval` renders `approval` (with wait duration), not `rebase`, regardless of submit errors.
- `rebase` label requires actual rebase activity (`rebase_attempts>0` or in-stage).
- `make build/test/lint` green.
