# GH-4771

**Created:** 2026-08-06

## Problem

GitHub Issue GH-4771: test(gate): docs-only fast path for the pre-push gate — skip Go steps when the push touches no code

## Problem

Docs-only pushes (`.agent/` closeouts, dispatch records, markers) pay the full 224-287s pre-push gate and race the daemon's merge cadence: on 2026-08-06 one docs commit took three gate runs to land (one flaky-test failure, two origin/main-advanced-mid-gate rejections). Measured: main advances ~12-29×/day, median gap ~21 min → a ~230s gate window has ~16-20% collision odds, worst during the 16:00 train hour. The gate script's own header still claims "Target: <30 seconds" (`scripts/pre-push-gate.sh:4`).

## Context (verified 2026-08-06)

- `.git/hooks/pre-push` is generated from the heredoc in `scripts/install-hooks.sh:128-173` and **never reads stdin** — the `<local_ref> <local_sha> <remote_ref> <remote_sha>` lines git provides are discarded. Hooks are untracked; ALL changes go into `install-hooks.sh` (regenerated by `make install-hooks`), never hand-edited into `.git/hooks/*`.
- Gate steps + measured cost (`scripts/pre-push-gate.sh:86-180`): build 1-5s · lint 4-12s · `go test -short -race ./...` 188-238s · check-secrets 3s · check-mocks 0s · check-graph 0s · check-integration 26-29s.
- Path-conditional precedent exists in this exact file: the pre-commit heredoc runs `check-graph.py` only when staged paths hit `.agent/knowledge/` (`install-hooks.sh:88-118`).
- **Must always run**: check-secrets (scans all tracked files; its own history note at `scripts/check-secret-patterns.sh:8-13` records that exempting non-test files let leaks through) and check-graph (exists because of the H3 drift incident — `.agent`-only pushes are exactly its case, TASK-425).
- **Safely skippable for a zero-`.go`/`go.mod`/`go.sum` diff**: build, lint, test-short, check-integration — verified that no Go test reads the repo's real `.agent/` tree (all 12 `.agent`-touching tests build fixtures in `t.TempDir()`).

## Acceptance

1. The pre-push hook reads the stdin ref updates; for each, computes the union diff `git diff --name-only <remote_sha>..<local_sha>`. A push is **docs-only** iff the union across all pushed refs contains zero paths matching `*.go`, `go.mod`, `go.sum`. Null-OID remote (new branch), deleted-ref pushes, empty/errored diffs → full gate (fail toward the full gate on any doubt).
2. Docs-only → the gate runs ONLY check-secrets + check-graph and prints an explicit banner naming the steps skipped and why (no silent skips). Target <10s.
3. Any code path in the union (including a mixed docs+code push) → full 7-step gate, byte-identical to today.
4. `make gate` (manual invocation, no stdin) always runs the full gate and must not break.
5. Fix the stale `[1/6]`…`[7/7]` step labels and the "Target: <30 seconds" header comment.
6. Tests: a shell harness (e.g. `scripts/test-prepush-fastpath.sh` run by check-integration or CI) exercising the classifier with fake stdin — docs-only, code-only, mixed, null-OID, deletion-only cases.
7. New SOP `.agent/sops/quality/pre-push-gate.md`: gate anatomy, fast-path rules, and the operator step — **`make install-hooks` must be re-run after merge** (also state this in the PR description).
